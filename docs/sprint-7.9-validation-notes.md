# Sprint 7.9 validation scenarios

1. Mura-style Over: home recent venue Over 2/5 (40%), home 10-match venue baseline <=50%, opponent away recent >=70% -> hard Premium veto.
2. Balanced strong Over: both venue sides >=60% recent -> no hard veto.
3. BTTS one-sided: one venue side <=40%, opposite side >=70%, with weak side baseline <=50% -> hard veto.
4. BTTS weak scorer: recent BTTS <=40% plus recent failed-to-score >=40% against an opposite venue side >=60% -> hard veto.
5. Moderate weakness between 40% and 60% -> progressive reliability/rank penalty, not automatic rejection.
